# Shell Experiments

## Various little shell scripts with various utilities

</div>

## Description

- Compatible at least with bash and zsh
- All scripts have at least the following two commands

### Help

```bash
./[scriptFileName] -h
```

This command decribes the usage of the called script in a man-like form

### Version

```bash
./[scriptFileName] -v
```

This command prints the version of the script and its name
